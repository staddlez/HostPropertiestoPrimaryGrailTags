Custom Tag Cleanup

Add or delete custom tags on monitored entities via CSV.

/api/v2/tags

CSV format

Required columns: hostname, id. Add one or both tag columns.

hostname id tagstodelete tagstoadd

Tags in each cell are comma-separated (quote the cell in Excel). Use key or key=value format.

hostname,id,tagstodelete,tagstoadd
xyz.host.net,HOST-12345,"key1,key2,env=prod","team=ops,newkey"
# Delete only
hostname,id,tagstodelete
xyz.host.net,HOST-12345,"key1,key2,key3"
# Add only
hostname,id,tagstoadd
xyz.host.net,HOST-12345,"team=ops,env=prod"
DELETE sends one request per tag key. POST batches all add-tags in one request per entity.
Delete all with key removes every tag matching the key regardless of value. Uncheck if you only want to remove a specific key=value pair.

OneAgent Remote Configuration

Build, validate, preview, and create remote config jobs from a CSV.

/api/v2/oneagents/remoteConfigurationManagement

CSV format

Required columns: entityName, entityID. Add any supported attribute columns.

group hostGroup hostProperty hostTag networkZone

Multiple values in one cell must be comma-separated and the cell quoted.

entityName,entityID,hostProperty,hostTag
server1,HOST-001,"app=web,env=prod","team=ops"
Dynatrace preview only works for some operation types (network zone, host group). Always Validate before creating.
Blank cells with set mode produce an error — cells must have values. Use clear mode to remove values.
